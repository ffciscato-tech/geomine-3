Cava & Pilha por Strings

v10.6 — a linha desenhada É o limite exterior e TODAS as strings têm os MESMOS vértices dela.
como funciona a edição
Editar uma string intermediária é igual a editar a externa — os mesmos handles, e nenhum vértice é criado pelo arrasto.

Sem nada congelado, o arrasto é LIVRE: o vértice vai exatamente para onde você soltar, em qualquer direção, e a cava é redesenhada a partir dele com face, berma e rampa nominais.

⤓ Finalizar (cava ou DCE): clique no botão e depois na linha onde o projeto deve TERMINAR. Ele só finaliza: não desenha mais nada, nem berma de arranque, nem rampa — e a última linha fica SOLTA: vira linha desenhada, com movimento livre (o vértice vai exatamente para onde você soltar) e independente do pit de fora. Com ela solta, ponha o nº de bancadas para o pit de dentro continuar dali para baixo, com rampa e parâmetros próprios.
Depois, para continuar a mina, você escolhe como começa o próximo limite: ⊙ Escolher linha existente (clique numa linha que já está no desenho) ou ✎ Novo limite (desenhar) (desenhe o polígono). No seletor ao lado diga se essa linha vale como CRISTA ou como PÉ — se for pé, o primeiro passo para dentro é a berma; se for crista, é a face.
✎ Novo limite (desenhar): em vez de aproveitar uma string, você desenha o polígono do próximo limite. No seletor ao lado diga se esse polígono é a CRISTA ou o PÉ — se for pé, o primeiro passo para dentro é a berma; se for crista, é a face.
Como a linha de um limite é FONTE (não string gerada), ela tem movimento livre e exato, e mexer num limite não mexe nos outros.

Quando a linha não comporta a profundidade, o projeto para e marca em vermelho onde a parede fecha.

Resultados
—
Método: a linha desenhada é a string exterior LITERAL do projeto (nenhuma suavização a toca) e as demais strings nascem por dentro, bancada a bancada. A rampa é POR TRECHOS cortados na face, com terminações retas e ortogonais — crista e pé convergem no ponto de chegada/saída de cada trecho. Largura e gradiente constantes (medidos no eixo), berma contínua por trás. Editar uma string (◇) regenera as de dentro a partir dela — mudar nº de bancos, a linha-base ou a rampa descarta as edições. Terreno na cota 0. Volumes por prismóide entre strings. Sem switchback nesta versão.

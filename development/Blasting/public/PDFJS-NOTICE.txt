GeoMine bundles these files inside its single-file HTML. The API module is
imported lazily from a Blob URL only when a local PDF is selected. A dedicated
worker performs parsing and is terminated at the end of each read. On file://
origins, the runtime adapter removes the worker's single ESM export and replaces
import.meta.url with self.location.href to use a classic Blob worker. This
avoids Chromium's restriction on module workers from opaque local-file origins;
the parsing code and the vendored distribution files remain unchanged.
No CDN, document upload, viewer, external credential, or remote OCR is used.
